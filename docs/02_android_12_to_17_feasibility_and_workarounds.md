# Phase 0 (b): Android 12 to 17 (`API 31–37`) & Per-Brand Feasibility Matrix

---

## 1. Per-Android-Version Behaviour & Feasibility Table (`Android 12` $\rightarrow$ `Android 17`)

| Android Release | API Level | Key OS Restrictions Introduced | What Works Without Root (`L1` / `L2`) | One-Time Setup Required (`L2` / `L3`) | What Is Impossible Without Root & Honest Workaround |
| :--- | :---: | :--- | :--- | :--- | :--- |
| **Android 12 / 12L** | **31 / 32** | • Microphone & Camera privacy indicators + system-wide Mic kill switch.<br>• Foreground service launch restrictions from background (`ForegroundServiceStartNotAllowedException`).<br>• Clipboard read toast notification.<br>• Permission auto-reset (`ACTION_AUTO_REVOKE_PERMISSIONS`).<br>• `BLUETOOTH_CONNECT` / `BLUETOOTH_SCAN` runtime permissions. | • Full `AudioRecord` + `AEC`/`NS`/`AGC` when started from visible Activity, `VoiceInteractionService` (`ROLE_ASSISTANT`), or notification tap.<br>• Detect all-zero PCM frames when user turns off system Mic toggle.<br>• Sensitive clipboard write without reading clipboard. | • Set OmniVoice as **Default Digital Assistant (`ROLE_ASSISTANT`)** for background/boot mic start.<br>• Disable **Pause app activity if unused** (`ACTION_AUTO_REVOKE_PERMISSIONS`). | • **Cannot hide the green microphone indicator** (enforced by SystemUI): documented honestly.<br>• **Cannot start mic FGS silently from `BOOT_COMPLETED` without `ROLE_ASSISTANT`**: falls back to a high-priority 1-tap `"Wake OmniVoice"` notification on boot. |
| **Android 13** | **33** | • `POST_NOTIFICATIONS` runtime permission.<br>• `NEARBY_WIFI_DEVICES` runtime permission.<br>• **Restricted Settings** blocks Accessibility & Notification Listener for sideloaded APKs.<br>• `ClipDescription.EXTRA_IS_SENSITIVE` hides clipboard preview.<br>• `SpeechRecognizer.createOnDeviceSpeechRecognizer()`. | • On-device STT with `triggerModelDownload` (`ur-PK`, `en-US`).<br>• Masked clipboard password injection (`EXTRA_IS_SENSITIVE`) + immediate clear. | • Sideloaded APK requires **App Info $\rightarrow$ `⋮` $\rightarrow$ Allow restricted settings** before enabling Accessibility or Notification Listener. | • **Cannot programmatically bypass Restricted Settings for a sideloaded APK**: our Permission Wizard detects when Accessibility is blocked and provides a 1-tap deep-link to App Info with visual instructions (`⋮ -> Allow restricted settings`), or ADB install (`adb install -g`). |
| **Android 14** | **34** | • Strict `FOREGROUND_SERVICE_MICROPHONE` enforcement (`SecurityException` if started from background without while-in-use permission).<br>• `USE_FULL_SCREEN_INTENT` restricted to calling/alarm apps unless granted via `ACTION_MANAGE_APP_USE_FULL_SCREEN_INTENT`.<br>• `accessibilityDataSensitive` view property introduced. | • `VoiceInteractionService` (`ROLE_ASSISTANT`) retains exemption to launch microphone session.<br>• Detect `node.isAccessibilityDataSensitive` and inform user honestly. | • Grant **Full-Screen Intent** (`Settings.ACTION_MANAGE_APP_USE_FULL_SCREEN_INTENT`) for lock-screen wake cards if not using assistant session. | • **Cannot read or click views marked `accessibilityDataSensitive="yes"`** by banking/password-manager apps: OmniVoice detects this flag and explains why the banking screen requires manual touch. |
| **Android 15** | **35** | • Harder Background Activity Launch (`BAL`) blocks (`PendingIntent` must explicitly opt in with `ActivityOptions.MODE_BACKGROUND_ACTIVITY_START_ALLOWED`).<br>• `SYSTEM_ALERT_WINDOW` overlays must be visibly rendered to grant BAL privileges.<br>• 16 KB ELF page alignment requirement for `.so` native libraries. | • Floating Mini-Orb overlay (`SYSTEM_ALERT_WINDOW`) + `VoiceInteractionSession` + `OmniAccessibilityService` launch activities reliably and verify foreground package. | • Grant **Display over other apps** (`SYSTEM_ALERT_WINDOW`). | • Pure JVM/Kotlin audio & NLU engines avoid 4 KB `.so` crashes; any optional native runtime (LiteRT-LM / ONNX) is wrapped in `UnsatisfiedLinkError` try/catch with graceful fallback to Tier B/C. |
| **Android 16** | **36** | • Strict edge-to-edge enforcement and predictive back.<br>• Enhanced notification cooldown and sensitive notification redaction on lock screen. | • Full edge-to-edge Compose UI + `BackHandler` integration.<br>• `NotificationListenerService` reads allowed messaging notifications. | • Standard Notification Listener + Accessibility setup. | • System OTP notifications redacted by OS on untrusted listeners: OmniVoice reads notifications only after user unlocks or via verified assistant session. |
| **Android 17** | **37** | • **Background-Audio Hardening**: background services without while-in-use capability cannot play audio, request `AudioFocus`, or change volume/ringer.<br>• **Advanced Protection Mode** (`AdvancedProtectionManager`): disables `AccessibilityService` for apps that are not genuine accessibility tools.<br>• Dynamic code loading (`System.load`) requires read-only files.<br>• `ACCESS_LOCAL_NETWORK` permission for LAN traffic. | • All audio playback, `AudioFocus`, and volume changes run inside the while-in-use `WakeWordForegroundService` / `VoiceInteractionService` and verify volume read-back.<br>• Detects `AdvancedProtectionManager` state. | • If user enables Android 17 **Advanced Protection Mode**, user must either turn off Advanced Protection for UI automation or use `L1` (SDK/Intents) + `L3` (Shizuku/ADB). | • **When Android 17 Advanced Protection is ON, `AccessibilityService` is forcibly disabled by the OS for non-accessibility-tool apps**: we do **not** falsely claim `isAccessibilityTool="true"`; instead we detect Advanced Protection, explain it clearly, and route commands through `L1` Official Intents and `L3` Shizuku/ADB. |

## 2. Capability Control Ladder (`L1 -> L2 -> L3 -> L4`)

| Capability | `L1` Official SDK / Intent (Zero Setup) | `L2` `OmniAccessibilityService` (One-Time Toggle) | `L3` Shizuku / ADB `WRITE_SECURE_SETTINGS` (Power User) | Verification Read-Back (`ActionVerifier`) |
| :--- | :--- | :--- | :--- | :--- |
| **Phone Calls (Dual-SIM)** | `TelecomManager.placeCall()` / `ACTION_CALL` with selected `PhoneAccountHandle` (`SIM 1` / `SIM 2`) | Click SIM selector dialog if OEM prompts | `cmd telecom place-call` | `TelephonyManager` call state $\neq$ `CALL_STATE_IDLE` |
| **Answer / End Call** | `TelecomManager.acceptRingingCall()` / `endCall()` | Click Answer/Decline on incoming call notification | `input keyevent KEYCODE_HEADSETHOOK` / `KEYCODE_ENDCALL` | Call state transition verified |
| **Send SMS (Dual-SIM)** | `SmsManager.createForSubscriptionId(subId).sendTextMessage()` | Type & send in Messages app | — | `sentIntent` `PendingIntent` == `Activity.RESULT_OK` |
| **WhatsApp Message / Call** | Query `ContactsContract.Data` (`vnd.android.cursor.item/vnd.com.whatsapp.profile` / `voip.call`) or `whatsapp://send?phone=...` | Find chat composer $\rightarrow$ `ACTION_SET_TEXT` $\rightarrow$ click Send (`com.whatsapp:id/send`) | — | Send button disappears & message bubble appears in chat tree |
| **Wi-Fi Turn On / Off** | `Settings.Panel.ACTION_INTERNET_CONNECTIVITY` / `ACTION_WIFI` | Auto-toggle Wi-Fi switch inside Internet Panel / Quick Settings tile | `Settings.Global.putInt(WIFI_ON, 1)` or `svc wifi enable` | `WifiManager.isWifiEnabled` == target |
| **Connect to Wi-Fi SSID with Password** | `Settings.ACTION_WIFI_ADD_NETWORKS` (API 31+) / `WifiNetworkSpecifier` | Open Wi-Fi list $\rightarrow$ tap SSID $\rightarrow$ inject password (`ACTION_SET_TEXT` or sensitive clipboard) $\rightarrow$ tap Connect | `cmd wifi connect-network <ssid> wpa2 <pass>` | `ConnectivityManager` active network has `NET_CAPABILITY_VALIDATED` + matching SSID |
| **Mobile Data Toggle** | `Settings.Panel.ACTION_INTERNET_CONNECTIVITY` | Tap Mobile Data tile in Quick Settings / Internet Panel | `svc data enable` / `disable` | `NetworkCapabilities.TRANSPORT_CELLULAR` state matches |
| **Volume & Ringer Control** | `AudioManager.setStreamVolume()` / `setRingerMode()` inside while-in-use FGS | Press volume panel sliders via Accessibility | `cmd media_session volume` | Read back `AudioManager.getStreamVolume()` == target (detects Android 17 background suppression) |
| **Unlock Locked Phone** | `Activity.setShowWhenLocked(true)` + `KeyguardManager.requestDismissKeyguard()` | Swipe keyguard + enter Keystore-encrypted PIN/pattern on keypad nodes | `input text <PIN> && input keyevent 66` | `KeyguardManager.isKeyguardLocked == false` |
| **Lock Phone Immediately** | `DevicePolicyManager.lockNow()` (via `OmniDeviceAdminReceiver`) | `AccessibilityService.performGlobalAction(GLOBAL_ACTION_LOCK_SCREEN)` | `input keyevent KEYCODE_SLEEP` | `PowerManager.isInteractive == false` or `isKeyguardLocked == true` |
